# Photos taken under water in shallow tropical sea

From Wikimedia Commons, 19 November 2026. Each is the copy Commons serves for 1600 pixels across, which is now
1920 pixels (the nearest standard size), or the original where that is smaller. None seems to use a flash
unless the entry says so. Two files are PNG because NOAA published them so.
